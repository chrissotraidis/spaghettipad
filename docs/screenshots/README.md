# SpaghettiPad screenshots

These captures document the current app. The four JPEGs are physical-iPad
captures used by the public README. The PNGs are retained development captures
from the iPad and iPhone Simulators.

| File | Capture | What it shows |
|---|---|---|

| `ipad-race-triple-shells.jpg` | Physical iPad | Analog touch racing and item use |
| `ipad-four-player-select.jpg` | Physical iPad | Four-player character selection |
| `ipad-race-jungle-hd.jpg` | Physical iPad | Enhanced textures during a DK's Jungle Parkway race |
| `ipad-touch-controls.png` | iPad Simulator | Touch-control layout |
| `ipad-2p-split-screen.png` | iPad Simulator | Two-player split-screen rendering |
| `ipad-settings.png` | iPad Simulator | Settings presentation |
| `ipad-tilt-controls.png` | iPad Simulator | Tilt controls |
| `iphone-settings.png` | iPhone Simulator | Compact-phone settings presentation |

The screenshots are retained here as release documentation. All game data and
optional texture-pack content used to create them was supplied locally and is
not included elsewhere in this repository.
